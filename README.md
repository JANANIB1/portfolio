Janani B — Portfolio

A modern personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion to showcase my software engineering, cybersecurity, AI, and blockchain projects. The website features smooth animations, responsive design, dark/light mode, and centralized content management for easy updates.

# Janani B — Portfolio

A modern personal portfolio built with **React, TypeScript, Vite, Tailwind CSS, and Framer Motion** to showcase my software engineering, cybersecurity, AI, and blockchain projects. The website features smooth animations, responsive design, dark/light mode, and centralized content management for easy updates.

## 🚀 Live Demo

**Portfolio:** [janani-b-portfolio](https://janani-b-portfolio.vercel.app/)

---

## 🛠️ Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lenis
- React Router
- Lucide React

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/JANANIB1/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:5173
```

---

## 📦 Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

---

## 🚀 Deployment

This project is deployed on **Vercel**.

To deploy your own version:

```bash
npm run build
```

Then import the repository into Vercel.
